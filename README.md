# Java Aggregation and Composition

A Java project completed as part of my Advanced Programming (Java) course. This assignment focuses on object-oriented design using aggregation and composition to build more complex applications from reusable classes.

## Projects Included

### Credit Card System
A credit card application that models customers, addresses, and monetary values using object aggregation. The project demonstrates copy constructors, object composition, encapsulation, and object interaction.

### MyLine
A geometric line class built using two `MyPoint` objects, demonstrating aggregation and geometric calculations.

### MyRectangle
A rectangle class composed of two `MyPoint` objects representing opposite corners.

### Campus Map
A campus mapping application that combines buildings, walkways, and fountains using previously created geometric classes. The application calculates walkway lengths, fountain areas, and manages relationships between campus objects.
